Preflight
1. Linux Podman host with a Compose provider must reach UniFi HTTPS plus Google and Cloudflare endpoints.
2. Upgrade self-hosted UniFi Network Application to 10.4.57 or newer. Never use legacy /api/s/{site}/cmd/stamgr APIs.
3. Firewall permits TCP/80 and TCP/443 to ORIGIN_BIND_IP only from organization and guest LANs. No WAN NAT/forwarding. Port 80 serves HTTPS redirects only.

Cloudflare
1. Create DNS-only A record PORTAL_HOSTNAME pointing to private ORIGIN_BIND_IP. Do not add public-routable A/AAAA or Cloudflare Tunnel. Add AAAA only with working local IPv6 routing and firewall.
2. Create dedicated API token restricted to portal zone with Zone:DNS:Edit and Zone:Zone:Read. Put token only in CLOUDFLARE_API_TOKEN for Caddy.
3. Permit private public-DNS answer through DNS-rebinding protection, or add matching local DNS override while retaining Cloudflare record for ACME DNS-01.

Google Cloud
1. Configure internal Workspace consent screen.
2. Create Web OAuth client with exact redirect URI: https://PORTAL_HOSTNAME/auth/google/callback.
3. No Admin SDK, offline access, or refresh-token scope.

UniFi
1. Network > Control Plane > Integrations: generate API key.
2. Configure captive SSID in Hotspot zone with External Portal URL https://PORTAL_HOSTNAME/portal. Staff and guests share this SSID; separate SSIDs may point to same URL.
3. Pre-authorization permits DNS, portal private IP TCP/443, accounts.google.com, oauth2.googleapis.com, and Google static hosts observed during OAuth. Block other LAN/private destinations.
4. Private controller CA must be installed into app container trust store. Never disable TLS validation.

Start
1. Run ./deploy.sh on Linux Podman host. Confirm detected LAN IP, enter portal hostname, and enter Cloudflare token at hidden prompt. No .env file is used.
2. Script generates app secrets, stores secrets in Podman secret store, builds images, and starts app plus Caddy in pod sengateway. Rootful Podman is simplest because pod binds ports 80/443.
3. Confirm podman ps --pod --filter pod=sengateway shows both containers, app is healthy, and port 8080 has no host listener. Confirm trusted HTTPS from guest VLAN and failure from off-site Internet.
4. Open one-time setup URL from podman logs sengateway-app. Configure initial admin, Google v2 client, exact lowercase Workspace domain, full UniFi Network API URL, API key, and site ID.
